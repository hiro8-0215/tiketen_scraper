## 論文での表記

- 価格は1枚当たり。売却確認時の掲載単価を成立価格の代理とし、手数料を含む実決済額とは区別する。
- Model16の `qwen_used: false` はQwenを価格回帰器として使わないという意味。QwenによるJSON意味特徴は使用した。BERT回帰は比較候補で、最終重みは0。
- 需要の「掲載継続・売却確認・削除確認」は観測できた状態。結果不明を出品継続や売却に置き換えない。代替の非出現には十分な観測範囲が必要。
- 11/27価格比較は売却144件・7公演。改良Model18のMAEは8,601円でModel16の9,063円を下回ったが、起点提示価格基準の3,936円には届かず、価格予測の事前封印も完了していない。需要・代替で改善した期間があっても、全期間の改善や買い時の実利益を示したわけではない。
- 第4・6・7章はモデル構成の説明と11月12日時点の結果。後の実験結果を加える場合は、別の表に起点・母集団・件数・モデル版を明記する。
